# Google Play 제출 직전 체크리스트

## 확정된 앱 정보

- 앱 이름: 청년혜택.zip
- 패키지 ID: `com.youthzip.app`
- 버전: `1.0` / versionCode `1`
- 최소 Android: API 24 (Android 7.0)
- 대상 Android: API 36
- 개인정보처리방침: `https://youthzip.pages.dev/privacy/`
- 문의: `https://youthzip.pages.dev/contact/`
- 광고: 첫 출시 버전에는 없음
- 로그인/회원가입: 없음

## Play Console에서 입력할 초안

- 짧은 설명: 지역·유형별 청년지원사업을 찾고 찜과 마감 알림으로 놓치지 마세요.
- 전체 설명: 청년혜택.zip은 청년 월세, 취업, 금융, 교육, 교통, 문화, 복지, 창업 지원사업을 한곳에서 찾는 앱입니다. 지역과 지원 유형, 신청 상태로 정책을 검색하고 관심 정책을 기기에 저장할 수 있습니다. 신청 마감일이 있는 정책은 로컬 알림을 설정할 수 있으며, 상세 화면에서 공식 공고와 신청처를 확인할 수 있습니다. 정책 내용은 변경될 수 있으므로 신청 전 공식 공고를 최종 확인해 주세요.
- 앱 카테고리: 라이프스타일
- 대상 연령: 만 18세 이상
- 콘텐츠 등급: 폭력·성적 콘텐츠·도박 없음

## 실제 제출 때만 진행

1. Google Play 개발자 계정의 앱 서명 키를 생성하고 안전한 별도 위치에 보관한다.
2. `keystore.properties`와 서명 설정을 추가한다. 키와 비밀번호는 Git에 올리지 않는다.
3. 서명된 release AAB를 생성한다.
4. 휴대전화/태블릿 스크린샷, 512px 아이콘, 1024×500 그래픽 이미지를 등록한다.
5. 데이터 보안 양식에서 로컬 찜·로컬 알림과 Cloudflare 통신 내용을 실제 동작 기준으로 신고한다.
6. 개인정보처리방침 URL, 광고 포함 여부, 앱 액세스, 대상 연령, 콘텐츠 등급을 최종 확인한다.
7. 내부 테스트 트랙에 먼저 올려 설치·알림·공식 링크를 실기기에서 확인한다.
8. 첫 심사 승인 후 필요할 때만 AdMob을 별도 버전으로 추가하고 개인정보처리방침과 데이터 보안 신고를 갱신한다.
